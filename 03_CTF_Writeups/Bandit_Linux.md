### Hot to Join

1. in your windows open terminal with press the Win + R and write 'cmd'
2. access connection with SSH in terminal, write the script bellow:
> ssh bandit0@bandit.labs.overthewire.org -p 2220
3. enter your password for first time
> bandit0
4. after you login in linux command line (LCI) you can searching password next level, password in file name 'readme'
5. if you find the next level password, you can use the password for login to next level
