# How to Use Java Script (JS)

## Essential

- Variable
- Data Types : string, bolean, integer
- Functions : tindakan rangkaian dari suatu task
- Loops : Pengulangan Task dalan suatu tindakan Fungsi
- Request-Response Cycle : client in web browser > web server dan akan menampilakn HTML, CSS dan JS

JavaScript adalah kode yang langsung diinterpretasikan di browser.

```

console.log("Hello, World!");

// Variable and Data Type
```
