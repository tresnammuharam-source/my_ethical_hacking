# Link For Your Check IP, User, Domain etc


## Tools Healty Checking

| Nama Web | Link Web | Kegunaan |
| --- | --- | --- |
| **Shodan** | https://www.shodan.io/ | Shodan mencari perangkat / Device yang terhubung ke internet |
| **Censys** | https://search.censys.io | Censys adalah platform yang digunakan untuk mencari dan menganalisis perangkat yang terhubung ke internet secara global |
| **VirusTotal** | https://www.virustotal.com | VirusTotal adalah layanan online yang digunakan untuk menganalisis file, URL, domain, atau IP address apakah mengandung malware atau aktivitas berbahaya. |
| **Have I Been Pwned** | https://haveibeenpwned.com | Have I Been Pwned adalah website yang digunakan untuk mengecek apakah email atau password kamu pernah bocor dalam data breach di internet. |
| **CVE** | https://cve.mitre.org , https://nvd.nist.gov , https://www.exploit-db.com | Common Vulnerabilities and Exposures (CVE) adalah sistem penamaan standar untuk kerentanan keamanan pada software atau sistem. CVE adalah ID unik untuk setiap vulnerability yang ditemukan di dunia cybersecurity. exp: CVE-YEAR-NUMBER |
| **IP Location** | https://www.iplocation.net/ip-lookup | Melihat Lokasi IP berada di negara mana |
| **DomainTools** | https://whois.domaintools.com/ | untuk melihat detail interfomasi tentang domain address atau IP Address |
